## Como trabalho com IA

IA é parte do processo de engenharia, com as mesmas exigências de qualquer outra parte:

- **Spec-Driven Development (SDD):** cada mudança passa por proposta, design e revisão no OpenSpec, e as regras de negócio são levantadas antes da primeira linha de código.
- **Quality Gates:** a CI compara testes, análise estática e cobertura com uma linha de base que não pode regredir, então a qualidade só melhora.
- **Context Engineering:** grafo do código, memória persistente via servidor MCP próprio e otimização de tokens, para que os agentes trabalhem com o contexto certo.
